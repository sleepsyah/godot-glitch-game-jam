# godot-glitch-game-jam: @ttract

Delving into the life of a teen influencer, @ttract is a narrative-style game where enemies are only click away. Suitable for a teen audience and inspired by early 2010s scene and emo aesthetics.

Play here: https://sleepsyah.itch.io/ttractfinalreal

@ttract was made by sleepsyah, sharifahana, and Sushmita-Jacob using Godot. Created for the Girls Got Game game jam, it is based on the theme "attraction."
