# godot-glitch-game-jam
@ttract on Godot
Delving into the life of a teen influencer, @ttract is a narrative-style game where enemies are only click away. Suitable for a teen audience and inspired by early 2010s scene and emo aesthetics. Created for the Girls Got Game game jam.
Play here: https://sleepsyah.itch.io/ttractfinalreal
